SEMESTER INTERNSHIP - TASKS 1 & 2
=================================

Included files
--------------
1. customer_data.csv
   - 500-row synthetic customer dataset for learning and demonstration.
   - Contains numerical and categorical features plus intentionally missing values and a few unusual income values.

2. Task_1_EDA.ipynb
   - Dataset inspection, descriptive statistics, missing-value analysis,
     distributions, boxplots, correlation heatmap and relationship plots.

3. Task_2_Preprocessing.ipynb
   - Reusable Scikit-learn pipeline for median/mode imputation,
     One-Hot Encoding and MinMax scaling.

How to run
----------
1. Put all three files in the same folder.
2. Open the folder in VS Code or upload it to Google Colab.
3. Install dependencies:
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
4. Open each notebook and run cells from top to bottom.
5. Check generated charts and output files.
